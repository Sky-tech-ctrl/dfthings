# dfthings · 三角洲熟图模拟器

《三角洲行动》烽火地带的熟图练习工具：第一人称 3D 跑图，刷卡进钥匙房，开箱子和搜包，然后撤离；另外有熟图测验和地图编辑器。

纯前端，不用安装依赖，**直接双击 `index.html` 就能玩**（Three.js 已放在 `vendor/` 里，离线也能用）。

## 玩法

- **进入对局**：出发前选好携带的房卡，然后在 3D 地图里自由跑图。
  - `WASD` 移动，`Shift` 冲刺，`空格` 跳，鼠标转视角
  - `E` 刷卡开门、输入密码、开箱或搜包；物品会像游戏里一样逐件显示，点击拿取，`F` 全部拿取
  - `Tab` 打开背包，`M` 打开全图，`Esc` 暂停
  - 在撤离点里站满 5 秒算撤离成功，超时没撤出去会丢掉所有物资
  - 「地图标签」设成「全部隐藏」时，门牌、区域名和小地图名称都不显示，适合练熟图
- **熟图测验**：每轮 10 题，题型有两种：「点出某个房间或撤离点在哪」和「看黄框选名字」。
- **地图编辑**：导入真实地图截图作底图，把区域、房间、箱子、撤离点和出生点拖到正确位置。修改会自动保存在浏览器里，对局和测验都会用新布局；也可以导出或导入 JSON 分享。

## 数据说明

- 钥匙房名单（玻璃房/非玻璃房）和各图区域名称、撤离条件，来自公开攻略整理。
- **区域方位和房间坐标是按攻略描述画的示意布局，不是官方坐标**，标着「示意」「待校对」的地方尤其不准。欢迎用地图编辑器校正后导出 JSON 提 PR：把 JSON 内容写进 `js/data.js` 末尾的 `DF.LAYOUTS['地图id']`，它会成为默认布局。
- 物品名称取自游戏，价值和掉率是模拟数值。
- 潮汐监狱实际是多层结构，这里压平成了一个平面。

## 文件结构

```

js/layout.js      由数据生成布局（房间排布、箱子散布、墙体与门）
js/map2d.js       2D 地图渲染（小地图 / 全图 / 测验 / 编辑器共用）
js/game3d.js      3D 第一人称对局
js/loot.js        掉落生成
js/quiz.js        熟图测验
js/editor.js      地图编辑器
js/main.js        页面流程
vendor/three.min.js  Three.js r149（MIT）
```
